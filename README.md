# Прогноз погоди (консольна програма)

Лабораторна робота 1. Консольна програма на C# (.NET 9), яка показує прогноз погоди
на 5 днів для будь-якого міста.

Автор: Кріль Артем, Джеш Артем, Ярослав. Група ІПЗ-11

## Можливості

- пошук міста за назвою (українською чи англійською)
- прогноз на 5 днів: мінімальна і максимальна температура, опади
- робота з кількома містами без перезапуску програми
- історія останніх 10 запитів, яка зберігається у файл `history.json`
- обробка помилок: порожній ввід, місто не знайдено, немає інтернету,
  сервер не відповів, неправильна відповідь сервера

## Джерело даних

[Open-Meteo](https://open-meteo.com): безкоштовне API, ключ не потрібен.
Використовуються два запити: геокодинг (назва міста → координати)
і прогноз (координати → погода).

## Запуск

1. Відкрити рішення у Visual Studio 2022 або новішій.
2. Натиснути Ctrl+F5.
3. Ввести назву міста. Команди: `історія`, `вихід`.

Потрібен інтернет і .NET 9 SDK.

## Структура проєкту

- `Program.cs`: ввід, вивід і основна логіка програми
- `Models/`: класи, у які перетворюється JSON (`GeoResult`, `GeoResponse`,
  `DailyData`, `ForecastResponse`, `HistoryEntry`)

## Можливі покращення(але мені лінь бо всю ніч робив, сорі)

- винести роботу з API в окремий клас `WeatherService`
- додати unit-тести
