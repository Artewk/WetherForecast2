# Тест-кейси

Практична робота №15. Основи тестування програмного забезпечення

Проєкт: консольна програма прогнозу погоди. Група ІПЗ-11, ЛНТУ

## 1. Що необхідно перевіряти

- **Функціональність** за User Stories US-1…US-10: пошук міста, прогноз у таблиці, кілька міст підряд, історія, вихід, вибір міста, очищення історії.
- **Обробку помилок:** порожній ввід, неіснуюче місто, відсутність інтернету, некоректна відповідь сервера.
- **Стійкість до некоректних даних:** зайві пробіли, невірний номер при виборі міста, пошкоджений файл історії.
- **Відображення:** коректні українські літери, формат таблиці.

## 2. Умови тестування

- Середовище: Windows, Visual Studio, .NET 9.
- Для більшості тестів потрібен робочий інтернет (крім TC-13).
- Перед тестами, які перевіряють історію, видалити файл history.json (папка bin/Debug/net9.0), щоб починати з порожньої історії.
- TC-08, TC-09, TC-16 перевіряються на версії після інтеграції історій US-9 та US-10.
