# Проєктування інтерфейсу користувача

Практична робота №8. Проєктування інтерфейсу користувача

Проєкт: консольна програма прогнозу погоди. Група ІПЗ-11, ЛНТУ

## 1. Особливості інтерфейсу

Програма консольна, тому «вікном» є вікно консолі, а «екраном» — те, що видно в ньому в певний момент. Взаємодія відбувається лише через текст: користувач вводить назву міста або команду, програма відповідає текстом. Керування повністю з клавіатури, миша не потрібна.

## 2. Основні екрани

| ID | Екран | Призначення | User Story |
| --- | --- | --- | --- |
| S1 | Запит міста | Вітання, список команд, рядок введення | US-1, US-5 |
| S2 | Прогноз | Таблиця прогнозу на 5 днів | US-2 |
| S3 | Повідомлення про помилку | Пояснює, що пішло не так | US-3, US-4 |
| S4 | Історія | Список останніх запитів | US-6, US-7 |
| S5 | Вихід | Прощання й закриття програми | US-8 |

| Звідки | Дія користувача або подія | Куди |
| --- | --- | --- |
| S1 | Введено існуюче місто | S2 |

| S1 | Команда «вихід» | S5 |

## 5. Макети екранів

Нижче — точний текст, який програма виводить у консолі. Числа у прогнозі — приклад, у реальній роботі вони залежать від дня й міста.

**S1. Запит міста**

```
Програма прогнозу погоди.
Команди: історія, вихід

Введіть місто: _
```

**S2. Прогноз**

```
Введіть місто: Луцьк

Прогноз для: Луцьк, Україна

Дата        Мін     Макс    Опади, мм
--------------------------------------
2026-11-21  4,3     11,7    0,0
2026-11-22  7,3     12,5    0,9
2026-11-23  7,4     12,4    0,5
2026-11-24  7,8     11,0    0,1
2026-11-25  6,2     12,1    5,4
```

**S3. Повідомлення про помилку** (одне з повідомлень, залежно від помилки)

```
Місто не знайдено.
Помилка: назву міста не введено.
Помилка мережі: перевірте інтернет-з'єднання або спробуйте пізніше.
Сервер не відповів вчасно. Спробуйте ще раз.
Не вдалося розібрати відповідь сервера.
```

**S4. Історія**

```
Введіть місто: історія

Останні запити:
1. 2026-11-21 10:15  Луцьк, Україна
2. 2026-11-21 10:17  Львів, Україна
```

Якщо історія порожня, програма виводить «Історія порожня.»

**S5. Вихід**

```
Введіть місто: вихід
До побачення!
```

## 6. Основні користувацькі сценарії

1. **Подивитися погоду.** S1 → користувач вводить «Луцьк» → S2 → повернення до S1.
2. **Помилка вводу.** S1 → користувач вводить «asdfgh» → S3 («Місто не знайдено.») → повернення до S1.
3. **Історія й вихід.** S1 → «історія» → S4 → повернення до S1 → «вихід» → S5.

## 7. Прототип у Figma

Цей розділ потрібно виконати в самій Figma, а макети та навігація вище дають усе, що для нього потрібно:

1. Створити файл у Figma і додати кадри (Frames) розміром близько 800×480: один кадр на кожен екран S1–S5 (S3 можна показати двома-трьома варіантами).
2. Залити кадри чорним кольором, текст — світлий моноширинний шрифт (Consolas або JetBrains Mono), щоб виглядало як консоль.
3. Вставити в кадри тексти з макетів вище.
4. Перемкнутися на вкладку Prototype і з’єднати кадри стрілками за таблицею переходів (дія On click).
5. Запустити режим Present і пройти три сценарії з прошки.
